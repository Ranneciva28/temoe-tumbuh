# Temoe Tumbuh

Lead-generation and market-validation platform for Temoe Tumbuh daycare.

## V1 Scope

- Public marketing homepage
- Interest form with attribution capture (UTM, fbclid, gclid, referrer, landing page)
- Thank-you conversion page
- Admin authentication
- Market validation dashboard
- Lead management and funnel status
- Homepage CMS
- Form builder
- Media manager
- Tracking settings for Meta Pixel/CAPI, GA4, and Google Ads

## Target Architecture

Laravel 12 + PHP 8.3+, MySQL/PostgreSQL, Blade/Tailwind, deployed to Tencent Cloud Lighthouse behind Cloudflare.

## Funnel

Visitor -> Start Form -> Submit Interest -> Qualified -> High Intent -> Reserved -> Lost
